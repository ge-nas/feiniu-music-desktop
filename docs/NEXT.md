# 下一版待优化

## 功能
- 歌单管理：新建 / 改名 / 加歌 / 删歌（playlist/*）
- 播放历史上报（play-history / event/report），让飞牛 App 也能看到
- 专辑 / 歌手详情超过 50 首的分页
- 搜索建议（/search/suggest）+ 输入防抖
- 收藏页取消收藏后立即移除该行
- 系统托盘、关闭到托盘、全局快捷键、桌面歌词
- 断网 / NAS 离线 / token 失效的友好提示与重连

## 技术债
- 转码兜底（APE / WMA / DSD 等浏览器不支持格式，接 /track/transcode）
- 播放失败重试与错误提示
- 安装包代码签名（去掉 SmartScreen 警告）
- macOS 打包（dmg，分 arm64/x64）
- 自动更新

## 已知小问题
- 专辑/歌手详情页无「加载更多」
- 队列抽屉无封面、不支持拖拽排序
- 首屏未做骨架屏
