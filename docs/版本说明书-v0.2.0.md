# 飞牛音乐 · 电脑版 v0.2.0 版本说明书

- 发布：2026-11-15
- 类型：桌面端（Windows x64，Electron）
- 上一个版本：v0.1.0（2026-11-12，仅飞牛账号网页授权登录）

## 这个版本解决什么问题

v0.1.0 只有一条登录路径：弹出一个内嵌的飞牛系统登录页，登录完再回跳授权。

实测发现：**这个内嵌登录窗口在 Electron 里必然失败**，无论密码对不对都提示「用户名或密码错误」。
（同一个密码在浏览器网页版可以正常登录；用 PAM 验证过系统密码也是对的。该页面会先用 RSA 公钥加密会话密钥、再用 AES 加密密码后提交，在 Electron 内提交的密文服务端解不开，于是统一回「用户名或密码错误」。http/https、改 UA、清缓存都试过，无效。）

结论：桌面端不该再依赖这个网页窗口。v0.2.0 改成**账号密码直登**。

## 新增功能

1. **账号密码直登（主登录方式）**
   - 登录弹窗三个输入框：服务器地址 / 账号 / 密码，点「登录」即可，全程不弹网页
   - 走飞牛音乐官方接口 `POST /music/api/v1/user/password-login`
   - 登录成功后自动调 `/user/me` 校验 token，校验不过不入库，避免留下脏 token
   - 回车键可直接提交；下次打开自动回填地址和账号
2. **错误提示说人话**
   - 密码错 → 「账号或密码不正确」（不再是一句笼统的登录失败）
   - 缺地址 / 缺账号 / 缺密码分别提示
3. **其他登录方式下沉**
   - 「用飞牛账号网页授权登录」和「粘贴 music-token」收进折叠区，保留给特殊账号或调试用

## 安全说明

- **密码不落盘**：只在这一次登录请求里用，不写配置、不写日志
- 本地只保存登录 token（`%USERPROFILE%\.fnmusic-player\config.json`），可随时「退出登录」清除
- 只连用户填写的 NAS，无任何第三方上报

## 打包踩坑（下次别重复）

1. `makensis` 碰到中文文件名会 **Segmentation fault**（本次是 `docs/开发者说明书.md|.html`）→ 打包目录内改成 ASCII 名（`dev-guide.md|.html`），源码目录保留中文名
2. `makensis` 不认中文路径（`/vol2/1000/开发的项目/...` 下 `File /r` 报 no files found）→ 先把 `build/` + `dist/` 拷到 `/tmp/bld` 再编
3. 安装版用 `SetCompressor /SOLID lzma`，280MB → 80MB，压缩耗时几分钟，别以为卡死
4. 改 exe 图标/版本：`node scripts/patch-exe.mjs dist/fnmusic-win32-x64/FnMusic.exe build/icon.ico /tmp/new.exe` 再覆盖
